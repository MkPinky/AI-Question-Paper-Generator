# AI-Powered Question Paper and Assessment Generator

An AI-powered web application that automatically generates question papers and teacher answer keys from an uploaded syllabus using Streamlit and the Groq API.

## Features

- Upload syllabus in PDF format.
- Select subject and difficulty level.
- Choose question types: MCQ, Short Answer and Long Answer.
- Configure the number of questions, total marks and exam duration.
- Generate student question papers.
- Generate separate teacher answer keys.
- Validate question count, Bloom's Taxonomy labels and total marks.
- Download question papers and answer keys as PDF and TXT files.

## Technology Stack

- Python
- Streamlit
- Groq API
- OpenAI GPT-OSS 20B
- PyPDF
- ReportLab
